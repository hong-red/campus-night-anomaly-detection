## 0. 一页速览

**问题**：无人巡逻车用激光雷达点云跟踪行人，得到 2D 轨迹时序 `(x,y)`，要在**端侧(RV1126)、
亚秒级、无 YOLO/无图像**地实时检测校园夜间异常行为（逗留、聚集、翻越禁区、徘徊、疾跑、折返、急停）。

**思路**：把"轨迹"变成"多维时序特征"，用两套互补的异常打分器，取 max 融合：

| 分支 | 方法 | 训练 | 覆盖的事件 |
|---|---|---|---|
| EVT/规则分支（方案1） | FluxEV-SPOT（EVT 无监督）+ 三项行为规则 | 无 | 长时间停留 / 地理围栏 / 聚集 / 急停 |
| 深度学习分支（方案2） | TCN 轨迹预测（自监督） | 只训正常轨迹 | 徘徊 / 疾跑 / 折返(zigzag) 等隐蔽运动异常 |

**核心结论**：规则分支管"规则域"（静止/空间/共现，对 TCN 不可见）；DL 分支管"预测域"
（运动模式，对 FluxEV 不可见）；两者 **相加(软+硬) 效果最好**（Stanford 均值 AUROC 0.824，
显著高于单独 0.694/0.664），且 **跨校互为验证集通过**（迁移 ≈ 域内）。

## 1. 核心算法

### 1.1 FluxEV —— EVT 无监督时序异常检测（WSDM 2021）

> 参考实现：`F:\仿真跑\FluxEV\`；主管线封装：`geolife_pipeline.py` / `sdd_common.py`。

把"非极值异常"通过**波动提取 + 两步平滑**转成"极值"，再用 EVT 自动定阈值：

1. **EWMA 预测**：`pred_err[i] = x[i] − EWMA(x[i−s_w : i])`，得到预测误差。
2. **一阶平滑**：对预测误差取滑动窗 `max`，得 `fs_err`，再取局部极大 `fs_err_lm`。
3. **二阶平滑**：对跨周期 `period` 的局部极大再取 `max`，得波动特征 `ss_err`。
4. **SPOT 定阈**：训练段（前一半）的 `ss_err` 拟合 GPD，MOM 估参 → 初始阈值 `z`；流式更新。
5. **连续分数**：`score = clip((ss_err − t0) / (z − t0), 0, 1)`（低于阈值→0，达阈值→1，中间为可疑度）。

三个波动特征通道（速度 / 加速度 / 方向变化率）各自独立跑 FluxEV，取 max 得到 `motion` 分数。

### 1.2 SPOT / GPD / MOM —— 极值阈值

- **SPOT**（Streaming Peaks-Over-Threshold）：基于极值理论(EVT)的流式峰值超阈值检测，
  用广义帕累托分布(GPD)对"超过初始阈值的峰值"建模，自动给出极值分位数作为告警阈值。
- **MOM**（Method of Moments）：GPD 参数的矩估计（相对 MLE 更快、更适合流式）。
- 代码：`FluxEV/spot_pipe.py`（SPOT 类），`geolife_pipeline.fluxev_score()`（分数化封装）。

### 1.3 行为规则 —— 硬性 if 条件（规则域）

| 规则 | 判定形式（f） | Geolife 阈值 | SDD 阈值 | 输出 |
|---|---|---|---|---|
| dwell 长时间停留 | 连续 `speed < V_STAT` 的时长 | lo=120s / hi=300s | lo=15s / hi=30s | 0~1 线性抬升 |
| gather 多人聚集 | `time窗` 内 `半径` 内 `≥3人` 共现 | 180s / 50m / 3人 | 5s / 5m / 3人 | clip(人数/(3−1), 0, 1) |
| geofence 地理围栏 | 点在多边形/圆内 | 多边形(带 30m ramp) | 圆(半径 12m/6m) | 0/1 或渐变 |

> 论据：这三类事件是**空间/跨轨迹共现/静止**属性，不改变单条轨迹的运动模式，因此单轨迹
> 运动模型对它们无判别力（实验证实 FluxEV motion AUROC≈0.5）；而 if 规则几何/计数精确。

### 1.4 TCN —— 轨迹预测深度学习分支（方案2）

> 代码：`F:\仿真跑\tcn_dl_branch\tcn_branch.py`；SDD 重训/打分：`sdd_common.py`。

- **架构**：`TCNPredictor` = 4 层扩张因果卷积（dilations=1,2,4,8, hidden=32, k=3, dropout=0.1）
  编码器 + 线性解码器；参数量 < 6 万。
- **输入/输出**：过去 16 帧 `(x,y)` 相对坐标（米）→ 预测未来 8 帧（dt=2s 或 1s）。
- **训练**：自监督 MSE，**只喂正常行走轨迹**（Geolife 或 SDD），学"正常人怎么走"。
- **推理分数**：`ADE = 平均位移误差(米)`，映射为 `S_dl ∈ [0,1]`。

### 1.5 分数标定与融合

- **sigmoid 标定**（默认）：`S_dl = sigmoid((ADE − μ)/σ − 2)`，μ/σ 由验证集正常窗口 ADE 分布标定。
- **z-clip 标定**（=置信门限）：`S_dl = clip((ADE − μ)/(3σ), 0, 1)`——ADE 不超 μ 就真零，等价于"S_dl 置信门限"。
- **融合**：
  - `S_ev` = FluxEV 运动分数 与 规则分数 取 max（方案1 输出）。
  - naive `S = max(S_ev, S_dl)` —— 会损害突停检测（实验证实）。
  - **gated** `S = max(S_ev, S_dl · [S_dl ≥ 0.5])` —— 建议的置信门限融合。

## 2. 两套方法（方案）

### 方案1：FluxEV-SPOT（EVT 无监督 + 行为规则）
- 轨迹 → 速度/加速度/方向变化率 → 各跑 FluxEV 取 max → 与 dwell/gather/geofence 规则取 max。
- 特点：**无需训练、可解释、极轻量**（纯 Python，适配 RV1126）。
- 盲区：隐蔽运动模式异常（徘徊/折返/疾跑）——FluxEV 特征域之外，AUROC≈0.5。

### 方案2：FluxEV-SPOT + TCN 打分分支（max 融合）
- 在方案1基础上加 TCN 轨迹预测分支，`S = max(S_ev, S_dl)`（建议 S_dl 加置信门限）。
- 特点：捕捉 FluxEV 特征域之外的隐蔽运动异常；仍无需标注异常轨迹。
- 盲区：原地逗留（静止 → 近零预测误差 → 对 TCN 不可见）。

## 6. 关键设计决策

1. **规则阈值随数据尺度重标定**：判定形式（持续停留/半径共现/圈内）不变，只改量纲——
   Geolife GPS 尺度（dwell 120s/300s、gather 50m/180s）→ SDD 俯拍剪辑尺度（dwell 15s/30s、gather 5m/5s）。
2. **TCN 时间分辨率随数据而定**：Geolife 用 dt=2s（长轨迹），SDD 轨迹短(30~150s) 用 dt=1s；
   交叉验证时统一到 dt=1s 才可比。
3. **坐标统一为米制**：Geolife 经纬度→局部平面米（等距圆柱近似）；SDD 像素→米（行人 bbox 主轴≈1.7m 身高估 m/px）。
4. **融合需置信门限**：naive `max(S_ev, S_dl)` 因 S_dl 的噪声地板污染正常段而损害突停检测，
   故对 S_dl 设门限（z-clip 真零地板，或 `S_dl≥0.5` 才放行）。
5. **Windows 依赖顺序**：先 `import torch` 再 `import numpy/pandas`（c10.dll 冲突）。
