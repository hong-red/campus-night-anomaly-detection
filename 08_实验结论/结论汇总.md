# 实验结论汇总

> 双分支轨迹异常检测（EVT/规则 ⊕ 自监督 TCN），清华 Geolife + 斯坦福 SDD 双数据集。
> 归档日期：2026-10-20。所有数字来自本包内已跑通的实验 JSON，可复现。
> **最终口径**：硬 = if 规则 max(dwell[lo=15s], gather, geofence)；软 = 本地 TCN（z-clip）；**硬加软 = 逐事件 max(硬, 软)**（分工，不是平均、不是逐帧门控融合）。主指标 **AUROC（区分度）**，准确率仅作补充。

---

## 一、总结论

**软（TCN）+ 硬（if 规则）按「负责分支」取 max 融合效果最好**，两分支严格互补：

- **规则分支**（if 规则，含 dwell 时间阈值）管「规则域」：静止、空间越界、跨轨迹共现——这些对 TCN 近乎随机（AUROC 0.45~0.63），if 规则精确命中（0.76~1.00）。
- **深度学习分支**（自监督 TCN）管「预测域」：徘徊/疾跑/蛇形等运动模式突变——这些对 if 规则/E VT 运动极值近乎随机（≈0.5），只有 TCN 有判别力（0.55~0.89）。
- **分工**：2× if-else（闯入/聚集）+ 1× if-else+EVT（逗留）+ 3× TCN（徘徊/疾跑/蛇形）；急停是第 7 类特例，由「EVT motion + 置信门控」负责。
- **硬加软 = max(硬, 软)** 覆盖全部 6 类事件。

## 三、三个核心贡献（EVT 的重要性）

1. **双分支框架**：硬规则 + 自监督 TCN，量化互补性，按「负责分支」max 融合覆盖全部 6+1 事件。

2. **诊断并修复 SPOT/GPD 静默退化（EVT 分支的价值）**：真实清华轨迹上，**纯静止轨迹 GPD 异常分数被抬高，异常率 96.4%**（vs 行走 22.45%），即「静止被全量误报」；标定段 exceedance ≤1 时方差 NaN → 全部打 1.0。加 `MIN_FIT_POINTS` 守卫后恢复判别力（**EVT 分支 AUROC 0.776 / AP 0.740 / P 0.896 / R 0.558 / F1 0.688**）。EVT 是整篇论文的方法基础（FluxEV-SPOT，WSDM 2021），虽然运动极值单独对六行为 ≈0.5，但它：① 是急停的唯一运动来源（0.618）；② 是唯一无监督、可解释、可边缘部署的分支。

3. **CPU-only 自监督 TCN**（55,920 参数，10 万窗口）：z-clip 真零地板 + 固定 0.5 阈值；徘徊/疾跑/蛇形 AUROC 0.55~0.89，盲区（静止逗留）由规则分支补齐。

## 四、局限性（诚实披露）

1. Geolife 是白天 GPS 数据，无 LiDAR 点云噪声，仅作预训练源。
2. 异常为「在正常轨迹上注入」而非真实采集；多人聚集无真实正样本。
3. 蛇形（zigzag）逐帧 0.547 最弱（贴随机线），窗口级 0.658 缓解。
4. 原地逗留「5 分钟才异常」的定义决定 acc@0.5 存在因果延迟天花板（≈83%）。
